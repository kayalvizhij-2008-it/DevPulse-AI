### 🌌 A Modern AI-Powered GitHub Profile Analyzer

DevPulse AI is a futuristic GitHub analytics website that helps users explore developer profiles, repositories, followers, coding activity, and AI-powered improvement suggestions using the GitHub REST API.

✨ Built with a premium glassmorphism UI, smooth animations, responsive layouts, and real-time API integration.
